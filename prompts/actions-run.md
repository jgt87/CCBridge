RUNNING COMMANDS
```text
ACTION run
COMMAND
```
runs a command in the project folder (see WHAT CAN RUN HERE) and sends you its output. Never run commands that send email, change calendars or delete data. Use the move and delete actions for files.

```text
ACTION test
PATH
```
runs the tests for PATH (else for what you changed) by the helper program's command and names failures that were already there; never guess a test command
