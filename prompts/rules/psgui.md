POWERSHELL WINDOW APPS
- Build the window with WPF in Windows PowerShell 5.1 (nothing to install): Add-Type -AssemblyName PresentationFramework, PresentationCore, WindowsBase first; the window in its own MainWindow.xaml next to the script (or a here-string), loaded with [Windows.Markup.XamlReader]::Parse(...). Windows Forms only when the person asks for it.
- XamlReader cannot take x:Class or event attributes (Click="...", Loaded="..."): give elements x:Name, find them with $window.FindName('NAME') and connect events in PowerShell ($button.Add_Click({ ... })).
- The look comes from the UI kit: before the window is parsed, put styles/kit/wpf/KitTheme.xaml (the helper program writes it from the project's colours) in the application's resources, so the window can use its styles: $app = [Windows.Application]::Current; if (-not $app) { $app = New-Object Windows.Application }; $app.Resources.MergedDictionaries.Add([Windows.Markup.XamlReader]::Parse([IO.File]::ReadAllText((Join-Path $root 'styles\kit\wpf\KitTheme.xaml')))); only then $window = [Windows.Markup.XamlReader]::Parse($xaml). Buttons, fields, tables (DataGrid, sortable), check boxes and progress bars then look like the kit; the main action uses Style="{StaticResource KitPrimaryButton}", headings KitTitle, small grey text KitMuted, panels <Border Style="{StaticResource KitPanel}">. Do not set colours or fonts of your own.
- Find the project folder from the script ($PSScriptRoot), never from the current folder. Long work (reading big files, web calls) must not freeze the window: keep it short, or show progress and let the window redraw ($window.Dispatcher.Invoke([action]{}, 'Background')).
- Start: a .cmd next to the script that runs powershell -NoProfile -ExecutionPolicy Bypass -STA -WindowStyle Hidden -File "%~dp0NAME.ps1", so a double click opens the window without a console. Errors at start go to a message box ([Windows.MessageBox]::Show), not only the console nobody sees.
- When the environment variable STREAMHUB_GUI_TEST is set, the helper program is only checking that the window opens: show the window without doing work at start (no file changes, no web calls); it closes the window itself.
