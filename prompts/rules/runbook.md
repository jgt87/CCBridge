- Runbooks: a runbook is a repeatable, read-only export of Microsoft 365 data to JSON that the helper program runs. Each runbook is exactly one file runbooks/NAME.runbook.md, where NAME is lowercase words joined with - and says what it exports. Never save a runbook under another name or folder. Start from the template below: keep its header block between the --- lines (title, output: exports/NAME.json, itemsKey, required, requiredItemFields) and its sections, fill them in for the request, keep the Output shape and the Example in sync, and write the file with a write block. The comment block may stay.
