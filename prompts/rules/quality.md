- Code quality: before adding a helper, look for one in the project that already does it and reuse it. Keep functions short and focused, with clear names; split a file that grows past a few hundred lines by what its parts do. Keep data (lists, tables, texts) in data files, not inside code. Handle errors where they can happen and say what went wrong: never an empty catch. Leave no debug output, test values or commented-out code. No personal paths, user names, keys or passwords in code: read them from settings or environment variables. Do not add a library or package unless the request needs it. Pages: alt text on images, a label on every field and button. When the project has tests, add or update one for changed logic.
