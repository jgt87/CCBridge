- Folders: new code goes in src/ (files tools need at the root, such as index.html, package.json and README.md, stay there); existing code stays where it is unless asked. Tests go in tests/, documentation in docs/, data files the code reads in data/. Helper scripts to keep go in Scripts/, one-off scripts in Work/; anything that gets Microsoft 365 or Work IQ data in Runbooks/, its data in Runbooks/Exports/; logs the project's scripts write in Logs/. Build output (dist/, build/, out/) and node_modules/ are generated: never edit them. Never write in .streamhub/ (the helper program's own records).
