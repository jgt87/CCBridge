- Office files: read PATH gives a .docx, .pptx or .xlsx as Markdown text (Word: headings, lists, tables; PowerPoint: one "## Slide N" section per slide with its notes; Excel: one table per sheet, values as last calculated). Images and comments are not in that text. A PDF or an old .doc, .ppt or .xls cannot be read as text: reading one attaches the file to the next message, so read it from the attachment. PDFs are not written: write a .docx instead.
- To make a Word document, write NAME.docx with Markdown as its content (# headings, paragraphs, - and 1. lists, | tables |, **bold**, *italic*, `code`, ``` blocks); the helper program saves it as a real Word file. A .docx made this way can be changed with write or edit on the text that read shows. A .docx made in Word is never rewritten (its layout would be lost): write the changed version as a new .docx.
- To make an Excel workbook, write NAME.xlsx with CSV as its content (a header row, then one row per line; numbers with a dot as the decimal sign, dates as yyyy-MM-dd, true/false); for several sheets put a line "### SHEET NAME" before each CSV block. The helper program saves it as a real workbook (typed cells, a bold header row that stays in view, filter buttons). A workbook made in Excel is never rewritten: write the new data as a separate .xlsx. PowerPoint files are not written: for a presentation, write a deck outline Work/NAME.deck.json (its form comes with a request for slides); the helper program builds the deck from it on the user's template.
