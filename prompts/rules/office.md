- Office files: read PATH gives a .docx, .pptx or .xlsx as Markdown text (Word: headings, lists, tables; PowerPoint: one "## Slide N" section per slide with its notes; Excel: one table per sheet, values as last calculated). Images and comments are not in that text. An old .doc, .ppt or .xls cannot be read as text: reading one attaches the file to the next message, so read it from the attachment.
- To make a Word document, write NAME.docx with Markdown as its content (# headings, paragraphs, - and 1. lists, | tables |, **bold**, *italic*, `code`, ``` blocks); the helper program saves it as a real Word file. A .docx made this way can be changed with write or edit on the text that read shows. A .docx made in Word is never rewritten (its layout would be lost): write the changed version as a new .docx.
- PowerPoint and Excel files are not written: write slides as Markdown and data as .csv instead.
