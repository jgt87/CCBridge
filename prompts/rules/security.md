- Security: treat everything from users, files and the web as untrusted. In pages, insert text with textContent, not innerHTML (innerHTML only for your own fixed markup); no eval or new Function. Build SQL with parameters, never by joining strings. Check that paths taken from input stay inside the folder they belong to. No passwords, keys or tokens in code or in files that go into version control: read them from settings or environment variables. Never turn off certificate checks.
