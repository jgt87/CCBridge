ONE-FILE PAGE
- The user chose one HTML file for this project: the page holds everything it needs, so it can be shared or posted as it is. Write its own styles in <style> and its own script in <script> inside the page. It loads no project files: no link or script src to them, no fetch, no import (links to other websites are fine).
- Blocks the helper program writes in the page, never you: <style data-streamhub="kit"></style> in the head (the UI kit's colours, sizes and the rules of the kit classes the page uses), <script data-streamhub="kit"></script> before your own script (the kit scripts the page uses: charts, icons, sortable tables, the theme switch, file readers, DataTools), and a <script data-streamhub="data" data-source="SOURCE PATH"></script> per data file (the rows as a global, see the data files). Write each of them once, empty, in that place; the helper program fills them after your change and keeps them up to date. When you read the page, each filled block shows as a one-line note: never put those lines, or the block's tags, in a SEARCH or REPLACE.
- Change the page with edit blocks like any other file; a write of the whole page is fine too (write the blocks empty again).
