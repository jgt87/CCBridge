- Tests: write them with the framework the project already uses, next to its other tests, named so they are found: Pester NAME.Tests.ps1, Python test_NAME.py, JavaScript NAME.test.js. When you send done, the helper program runs the tests for the changed files and sends failures back: fix the code, or change a test only when it checks the old behaviour on purpose. Tests may not need the internet, real accounts or files outside the project.
