UI KIT
- The project has a UI kit. styles/kit/tokens.css holds the colours and sizes (the project's own: restyle there). styles/kit/kit.css holds the components, and the helper program writes it: after each change it has the rules of every kit class your pages use, so use a class and its CSS follows; never edit kit.css. Link tokens.css, then kit.css, before your own styles.
- Build interfaces from the kit's classes before writing new CSS. The whole kit is in .streamhub/ui-kit/ (read-only, the kit's catalogue): read the matching section of .streamhub/ui-kit/kit-examples.html before you use a component. Kit scripts and React parts come the same way: refer to styles/kit/NAME (a script tag, or an import from styles/kit/react/) and the helper program adds that file, with what it needs, after your change.
- Colours: use the working tokens (--kit-accent, --kit-text, --kit-chart-1...); they already pick readable colours for light and dark. With the blue palette the named colours are --kit-palette-* (each with -1 lighter and -2 darker variations): blue is the primary accent, light blue the secondary one for decoration and highlights. The only gradient is var(--kit-gradient) (kit-gradient, kit-band), for decorative areas, never behind small text.
- Restyle through the tokens (var(--kit-...)); do not hard-code colours, sizes or shadows. Your own CSS uses the same tokens. Keep text readable in light and dark (WCAG AA: 4.5:1 for text, 3:1 for large text and for the edges of fields and buttons); the helper program measures it.
- Components: kit-btn (--primary --ghost --danger --sm); kit-field kit-label kit-input kit-select kit-textarea kit-help kit-error-text kit-check kit-form; kit-toolbar kit-segmented; kit-table-wrap kit-table kit-num; kit-badge (--accent --ok --warn --error); kit-tabs kit-tab; kit-split kit-nav kit-nav__item kit-panel kit-panel__head; kit-figures kit-figure__label kit-figure__value; kit-notice (--ok --warn --error); kit-empty; kit-dialog; kit-stack kit-row kit-grid kit-divider; kit-h1 kit-h2 kit-h3 kit-muted kit-small kit-mono kit-link kit-kbd kit-spinner; kit-page and kit-container on the page itself.
- Interactive parts (need styles/kit/kit.js after the markup; they report through DOM events): kit-btn--hold with data-kit-hold (event kit:hold); kit-search with data-kit-search, kit-search__list, kit-search__item, kit-search__meta (kit:pick); kit-drop with data-kit-drop, kit-drop__title, kit-drop__files, kit-progress, kit-progress__bar (kit:files); kit-tabs--animated and kit-segmented--animated (kit:select); kit-loading with kit-loading__text; kit-composer with kit-composer__actions. In a React project use styles/kit/react/ instead: HoldButton, SearchBox, DropZone, Tabs, Segmented, Loading, Composer, CommandButton.
- Icons (Lucide, any icon name): <span data-kit-icon="NAME" aria-hidden="true"></span>, loaded by styles/kit/kit-icons.js (include it after the markup); the helper program adds the icons you use. A button with only an icon needs aria-label (kit-btn kit-btn--icon). React: Icon from styles/kit/react/.
- Charts: styles/kit/kit-charts.js draws them on the kit's colours (no library). Write <div class="kit-chart" data-kit-chart="bar|line|area|ring|gauge|heatmap|sparkline" data-kit-data='JSON' aria-label="WHAT IT SHOWS"></div> (see the charts section of .streamhub/ui-kit/kit-examples.html), or call KitCharts.bar(element, data) from code; React: Chart from styles/kit/react/.
- Reading files a person picks or drops (in the page, nothing uploaded): styles/kit/kit-data.js (include it before your script). KitData.readFile(file) returns a promise of { kind: "table", sheets, rows } for CSV, TSV and Excel (values typed: numbers, true/false, dates as yyyy-MM-dd text, empty cells null), { kind: "json", data }, { kind: "document", blocks, text } for Word, { kind: "slides", slides, text } for PowerPoint, { kind: "pdf", pages, text }; use KitData.accept on the file input. Never write your own CSV, Excel or Office parser. React: useFileData from styles/kit/react/. PDF: include styles/kit/vendor/pdfjs/pdf.min.js and pdf.worker.min.js before kit-data.js.
- Page grid: put the page in kit-container (header contents too: kit-header > kit-container), so everything shares one left and right edge (--kit-page-width, --kit-page-pad).
- Type is Arial (--kit-font); headings and labels in sentence case, never all capitals.
- Avoid: gradient text, thick coloured side stripes on boxes, decorative blur or glass effects, big hero numbers with tiny labels, rows of identical cards, panels inside panels.
