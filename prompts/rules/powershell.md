Avoid [Type]::Member (the chat can damage it): use -match, -replace or -split, cmdlets, or call the method on a cast value, for example ([regex]'PATTERN').Match(TEXT).
- PowerShell 5.1 traps: variable names ignore case (a $to or a foreach ($to ...) overwrites the parameter $To); wrap what you count in @() (one object has no .Count); return lists plainly (return , $list inside @(...) nests them); use $Matches only inside if (TEXT -match 'PATTERN') { ... }; never name a function like a built-in cmdlet.
