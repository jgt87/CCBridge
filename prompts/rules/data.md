- Data files (CSV, Excel, JSON): find the delimiter (; is common in European exports), the encoding (UTF-8 with or without BOM, or Windows-1252) and the decimal separator (a comma in many locales) before parsing. Read columns by their header name, never by position. Parse dates with an explicit format and say which time zone they are in. Check the data (empty rows, missing columns, wrong types) before writing results, and write UTF-8 CSV with a header. Work on copies: source data stays as it is.
