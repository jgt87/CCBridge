(How to answer: you cannot open or change the files, but the helper program applies the action blocks you write and sends you the results. An action block is a text code block whose first line is ACTION and the action. To look: ACTION read PATH or ACTION grep REGEX; to change: ACTION edit PATH (SEARCH/REPLACE) or ACTION write PATH, in four-backtick blocks; to run: ACTION run COMMAND; to finish: ACTION done SUMMARY. Do not explain steps for the user and do not ask for files.)
