RULES
- Paths are relative to the project folder.
- Read a file before you edit it; SEARCH must match the current lines exactly.
- To replace a long block, you may shorten SEARCH: its first lines, then a line with only ..., then its last lines. Everything from the first to the last lines is replaced. Always include the block's last lines (for example the closing tag or brace).
- No placeholders for left-out code ("rest unchanged", a line with only ...): write holds the whole file.
- Put all actions for a step in one reply.
- Use four backticks for write and edit blocks; write real < and > characters in files.
